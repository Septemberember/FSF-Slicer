# Artifact Status

## Current status

The current `main` branch is an illustrative preview for reviewing repository organization, schemas, and validation rules. It is not the research artifact described in the manuscript.

## Included

- Paper-reported category-level values transcribed from Tables 2-4.
- Deterministic synthetic manifests and task-level records.
- Ten synthetic RQ2 runs per task.
- Automated structural and aggregate validation.
- Documentation of the expected tool interface and data fields.

## Not included

- The FSF-guided Java slicing implementation.
- The exact 250-program empirical benchmark manifest.
- The 740 manually prepared functional scenarios.
- The executable slices generated in the experiment.
- Task-level empirical RQ1, RQ2, or RQ3 measurements.
- Dependency lockfiles and the cluster execution environment used in the study.

## Publication rule

The preview must not be tagged as a research-artifact release, assigned a DOI, or cited as empirical evidence. Every generated record must retain the `SYNTHETIC_ILLUSTRATIVE` label until it is replaced by traceable experimental output.
