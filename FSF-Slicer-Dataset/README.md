# FSF-Slicer Dataset

This dataset contains 250 Java programs and 740 functional scenarios in five control-flow categories.

| Directory | Programs | Scenarios |
|---|---:|---:|
| `Branched3/` | 100 | 339 |
| `Sequential3/` | 63 | 137 |
| `Single-path-Loop3/` | 21 | 57 |
| `Multi-path-Loop3/` | 31 | 104 |
| `Nested-Loop3/` | 35 | 103 |
| **Total** | **250** | **740** |

Each category contains one folder per program. Each program folder contains a Java source file (`.java`) and its matching Functional Scenario Form specification (`.fsf.txt`). In each scenario, `Tn` describes the input condition and `Dn` describes the expected outcome.
