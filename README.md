# FSF-Slicer

The official reproducibility artifact is being prepared for release.

A repository-schema and data-validation preview is available on the [`synthetic-preview`](https://github.com/Septemberember/FSF-Slicer/tree/synthetic-preview) branch. Its generated task-level records are explicitly synthetic and illustrative; they are not empirical evidence from the paper experiment.

The final artifact will be published on this branch only after the Java implementation, exact benchmark manifest, reviewed functional scenarios, executable slices, raw task-level measurements, dependency specifications, and redistribution notices have passed the repository validation gates.
