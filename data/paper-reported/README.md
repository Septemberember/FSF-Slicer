# Paper-Reported Aggregates

This directory contains machine-readable transcriptions of manuscript Tables 2-4. These category-level values are kept separate from the generated records under `data/synthetic/`.

- `rq1_category_summary.csv` records retained LOC, executable-statement, and cyclomatic-complexity ratios.
- `rq2_category_summary.csv` records dynamic-execution, path-derivation, SMT-solving, and total-time ratios.
- `rq3_category_summary.csv` records definite/inconclusive availability and judgment agreement.

The `source` column identifies the manuscript table. These summaries do not provide task-level provenance and cannot replace the missing raw experiment data.
